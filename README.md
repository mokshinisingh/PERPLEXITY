# 🧠 Perplexity Explorer

**Explore how Language Models understand sentences through Token Probabilities and Perplexity.**

Perplexity Explorer is an interactive, browser-based educational tool that demonstrates how language models predict text, calculate token probabilities, and measure perplexity.

It uses a real GPT-2-based language model through **Transformers.js** to help users understand how machines process and predict language.

---

## 🚀 Features

### 1. Sentence Input
- Enter any sentence to calculate its perplexity.
- Includes three sample sentences:
  - `I love Python`
  - `Python love I`
  - `The capital of France is Paris`
- Lazy-loads the language model when the calculation button is first clicked.

### 2. Token Probability Analysis
- Breaks sentences into individual tokens.
- Displays the probability of each token.
- Shows the inverse probability (1/P) for every token.
- Calculates perplexity using token probabilities.

### 3. Next Token Prediction
- Displays the top 8 predicted next tokens.
- Visualizes prediction probabilities using horizontal bars.
- Highlights the most probable next token.

### 4. Try It by Hand
A simulated environment to understand perplexity without running the language model.

Includes three presets:
- **I love Python:** Probabilities of 0.5, 0.8, 0.2.
- **All 1/8:** Eight tokens with equal probability of 0.125.
- **One Surprising Word:** Probabilities of 0.9, 0.9, 0.9, 0.01.

Users can:
- Add or remove tokens.
- Enter custom token names.
- Change probabilities.
- See perplexity calculations update instantly.

*Note: Section 4 uses manually entered probabilities and is simulated, not generated by the language model.*

## 📐 Understanding Perplexity

Perplexity measures how well a language model predicts a sequence of tokens.

A lower perplexity generally indicates that the model finds the sentence more predictable.

### Mathematical Formula

\[
PP = \left(\prod_{i=1}^{N}\frac{1}{P(w_i)}\right)^{1/N}
\]

Where:

- \(N\) = Total number of tokens.
- \(P(w_i)\) = Probability assigned to token \(i\).
- \(PP\) = Perplexity.

To avoid numerical overflow when multiplying many probabilities, the project uses the logarithmic formula:

\[
PP = \exp\left(-\frac{1}{N}\sum_{i=1}^{N}\ln P(w_i)\right)
\]

### Example

For the sentence `I love Python`, using simulated probabilities:

| Token | Probability |
|---|---:|
| I | 0.5 |
| love | 0.8 |
| Python | 0.2 |

\[
PP = \left(\frac{1}{0.5}\times\frac{1}{0.8}\times\frac{1}{0.2}\right)^{1/3}
\]

\[
PP = (12.5)^{1/3}
\]

**Perplexity ≈ 2.32**

## ⚙️ How to Run the Project

### Prerequisites
- A modern web browser.
- Internet connection to download Transformers.js and the model.
- A code editor such as VS Code or Antigravity.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/perplexity-explorer.git
```

**2. Navigate into the project**

```bash
cd perplexity-explorer
```

**3. Open the project**

Make sure `index.html` is in the project folder.

Run a local development server, for example:

```bash
python3 -m http.server 8000
```

**4. Open in your browser**

Visit:

```text
http://localhost:8000
```

Click Calculate Perplexity to load the model and begin exploring.
